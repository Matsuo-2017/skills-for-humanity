Scope: closed-weight, API-served models only. Open-weight models (DeepSeek V4, Qwen 3.7/3.8, GLM-5.2, Kimi K2.6, MiniMax M3) are mentioned only where they appear on the same leaderboard rows as proprietary models.

## Key Question 1: Which frontier models were released in 2026 and what are their reasoning-specific features?

### Takeaway
Between June and September 2026 every major closed lab shipped a new flagship: Anthropic (Fable 5 / Mythos 5 in June; Fable 5.1 / Mythos 5.1 on Sept 1; Opus 5.5 on Sept 22; Sonnet 5.5 on Sept 28), OpenAI (GPT-5.6 Sol/Terra/Luna in July; GPT-6 Astra on Sept 3–4; GPT-6 Sol/Luna on Sept 22), Google (Gemini 3 Deep Think Feb 12; Gemini 3.1 Pro Feb 19; Gemini 3.5 Flash May 19; Gemini 3.8 Flash Sept 2), xAI (Grok 4.7 on Sept 21; Grok 5 still unreleased) and Meta (Muse Spark 1.3 on Sept 2). The reasoning-mode trend is "always-on adaptive thinking steered by an effort knob" (Anthropic, OpenAI, Meta) rather than user-set token budgets, and the raw chain of thought is hidden by every vendor.

### Inferences
- The industry has converged on a single control surface for reasoning depth: a discrete effort level (Anthropic: low→max; OpenAI: low→max; Google: low/medium/high; Meta: up to xhigh/max) with adaptive allocation inside each level. User-specified thinking-token budgets are effectively gone from the top tier (Anthropic rejects them outright).
- Anthropic and OpenAI have both adopted a two-tier release pattern: a flagship "reasoning" model at $10/$50 (Fable 5.1, GPT-6 Astra) and a cheaper "workhorse" at $2–4 / $10–20 (Opus 5.5, Sonnet 5.5, GPT-6 Sol). Pricing parity at the top tier ($10/$50 for both Fable 5.1 and Astra) looks deliberate.
- "Same model, different safeguards" (Fable/Mythos) and "Critical cyber classification with admin-gated rollout" (Astra) mean the most capable models of both leading labs now ship with access tiers keyed to cybersecurity risk.

## Key Question 3: What are the differences between Claude Fable 5.1 and Claude Mythos 5.1?

### Takeaway
Per Anthropic's own pages, Fable 5.1 and Mythos 5.1 are the same underlying model with identical specs and pricing; the only differences are safeguards (Mythos has some cyber/bio safeguards lifted), access (Mythos is Project Glasswing / verification-program only, US organizations at present), one API behavior (Mythos skips the thinking-block prefix check), and a small benchmark delta on Terminal-Bench 4.0 (60.9% vs 55.8%) that presumably reflects the removed refusals.

## Key Question 4: Which models expose their reasoning traces, and which support tool use inside reasoning?

### Takeaway
No frontier vendor returns the raw chain of thought in September 2026: Anthropic returns omitted-by-default or summarized thinking plus encrypted, model-bound thinking blocks; OpenAI's GPT-6 Astra goes further by moving part of its reasoning into hidden recurrent state so there is less verbalized trace to show; Google returns thought summaries plus encrypted thought signatures. Tool use inside reasoning (interleaved thinking) is automatic on Claude 5.x; OpenAI, Google and xAI all ship tool-calling agents but the sources found do not document reasoning-internal tool calls in detail.

### Cited Findings
- Anthropic (Fable 5.1, Mythos 5.1, and by the "unchanged from Fable 5" note, the whole 5.x line): `thinking.display` defaults to `"omitted"`; `"summarized"` is available; "the raw chain of thought is never returned"; "Reasoning between tool calls appears in thinking blocks rather than text, and interleaved thinking is automatic with no beta header"; thinking blocks are cryptographically bound to the producing model and conversation prefix and must be passed back unchanged — [What's new in Fable 5.1](https://platform.claude.com/docs/en/models/fable-5-1/whats-new-fable-5-1)
- Anthropic's `display: "updates"` (beta, header `thinking-display-updates-2026-08-18`) exposes short human-readable progress notes between tool calls while keeping reasoning hidden — [What's new in Fable 5.1](https://platform.claude.com/docs/en/models/fable-5-1/whats-new-fable-5-1)
- OpenAI GPT-6 Astra: recurrent-depth / looped-transformer design "carries part of its intermediate thought in hidden state rather than in language tokens"; the system card "confirms that Astra's chain-of-thought monitorability is lower than that of earlier models" — [Kingy AI](https://kingy.ai/blog/recurrent-depth-openai-astra/); [Raschka](https://magazine.sebastianraschka.com/p/gpt-6-astra-looped-transformers-and); [Al Jazeera](https://www.aljazeera.com/economy/2026/9/4/openai-unveils-gpt-6-astra-amid-rising-scrutiny-and-safety); primary (blocked): [OpenAI Deployment Safety Hub](https://deploymentsafety.openai.com/gpt-6-astra)
- Cross-vendor mechanism (as of mid-2026): GPT-5.6, Claude Opus 4.8 and Gemini 3 all "construct hidden chain-of-thought processing traces" and their APIs "transmit the reasoning trace as an encrypted, base64-encoded envelope that the client passes back on subsequent calls"; Google uses encrypted "thought signatures" required for tool calling; Anthropic "carries full reasoning in an encrypted signature"; Grok's API exposes reasoning content with blank and redacted-with-summary cases — [Cybersecurity News](https://cybersecuritynews.com/top-ai-models-apis-flaw-exposes-hidden-reasoning/); [Inspect AI reasoning docs](https://inspect.aisi.org.uk/reasoning.html); [inspect_ai PR #4979 on Gemini signature-only thoughts](https://github.com/UKGovernmentBEIS/inspect_ai/pull/4979)
- August 2026 research ("Stealing Reasoning Traces from Proprietary LLM APIs") showed the encrypted reasoning blocks from Anthropic, OpenAI and Google could be replayed into a cheaper model in the same family, which then printed the hidden reasoning in plaintext — [arXiv 2608.09867](https://arxiv.org/html/2608.09867v1); [The Hacker News, Aug 2026](https://thehackernews.com/2026/08/openai-anthropic-google-api-flaw-let.html). Anthropic's Fable 5.1 rule that "no earlier model reads Claude Fable 5.1's" thinking blocks (one-directional binding) is consistent with a mitigation — [What's new in Fable 5.1](https://platform.claude.com/docs/en/models/fable-5-1/whats-new-fable-5-1)
- Gemini 3.1 Pro exposes Low/Medium/High thinking levels; Grok 4.7 offers "configurable reasoning" with function calling, web/X search and code execution — [Apiyi](https://help.apiyi.com/en/gemini-3-1-pro-preview-thinking-level-control-guide-en.html); [CometAPI Grok 4.7](https://www.cometapi.com/what-is-grok-4-7/)

### Inferences
- "Exposes reasoning traces" is best answered as a spectrum: Claude (summaries + progress updates, encrypted blocks), Gemini (thought summaries + signatures), Grok (reasoning content, sometimes redacted), GPT-6 Astra (least: architecture reduces verbalized reasoning; monitorability regression acknowledged in its own system card). None returns raw CoT.
- Tool use inside reasoning is documented as automatic on Claude 5.x; for the other vendors the sources found describe agentic tool calling but not whether tool calls occur inside the hidden reasoning pass. Mark as "not documented in sources found," not "unsupported."

### Gaps
- Could not read OpenAI's or Google's API docs to confirm exact reasoning-summary options (e.g., OpenAI `reasoning.summary`, Gemini `include_thoughts`) as of Sept 2026.
- No source describes whether Astra's recurrent-depth passes can invoke tools mid-loop.
- xAI's reasoning-trace policy for Grok 4.7 specifically was not found.
