# Skill Libraries and Prompt-Methodology Packs for Structured Reasoning (state as of 2026-09-29)

Scope: the Agent Skills (SKILL.md) standard, official and community skill collections, reasoning/mental-model skill packs, marketplaces, and skill-evaluation tooling. Model comparisons and orchestration frameworks are out of scope. All star/installs counts are point-in-time snapshots taken 2026-09-29 unless a different date is given. Items marked **[unverified]** come only from search-engine snippets because the primary page was blocked by the research proxy (agentskills.io, arxiv.org, huggingface.co, aaif.io, geminicli.com, marktechpost.com, agentman.ai, emergentmind.com were all unreachable).

## Key Question 1: State of the Agent Skills standard (spec, governance, host support) as of September 2026

### Takeaway
Agent Skills is a minimal, stable open format (a folder with `SKILL.md` + YAML frontmatter with two required fields) originally released by Anthropic as an open standard on 2025-12-18, now stewarded under the Agentic AI Foundation (Linux Foundation), and read natively by 20-40 hosts including Claude Code, OpenAI Codex, Gemini CLI, Cursor, GitHub Copilot and VS Code. The spec is published as an unversioned "living document"; no numbered spec version could be found.

### Cited Findings
- Anthropic released Agent Skills as an open standard on December 18, 2025, publishing the specification and SDK; the standard lives at agentskills.io and is described as adopted by "26+ platforms including Claude, OpenAI Codex, Gemini CLI, GitHub Copilot, Cursor, and VS Code" **[unverified, search snippet]** — [Strapi blog](https://strapi.io/blog/what-are-agent-skills-and-how-to-use-them); [inference.sh overview](https://inference.sh/blog/skills/agent-skills-overview)
- As of June 2026, "roughly 40 skills-compatible products appear on the official agentskills.io showcase" **[unverified, search snippet; agentman.ai blocked]** — [Agentman ecosystem report 2026](https://agentman.ai/blog/agent-skills-ecosystem-report-2026)
- Governance: "Anthropic stewards the Agent Skills specification through the Agentic AI Foundation. The specification is maintained as a living document at agentskills.io/specification" **[unverified snippet]** — [Agentailor: Top AI Agent Standards 2026](https://blog.agentailor.com/posts/top-ai-agent-standards-2026); a second source says governance "moved to the Agentic AI Foundation (AAIF) under the Linux Foundation, the same body that now stewards MCP" and that the format is "read natively by Codex, Cursor, GitHub Copilot, Gemini CLI, Aider, Windsurf, Zed, Devin, Amp, Factory, Jules, and VS Code, among 20+ others" **[unverified snippet]** — [Product Builder cross-tool guide](https://www.productbuilder.net/learn/agent-config-files)

### Inferences
- The spec is deliberately unversioned; compatibility claims across hosts rest on the two required fields and the folder layout, while everything richer (invocation control, subagent execution, hooks, evals) is host-specific. Portability of *reasoning* skills is therefore high because they are usually pure markdown with no scripts.
- The Codex catalog's deprecation in favor of "plugins" and AAIF's "Agent Plugins 1.0" suggest that by late 2026 the unit of distribution is shifting from single skills toward plugin bundles (skills + hooks + agents), while SKILL.md remains the atomic format.

### Gaps
- I could not read agentskills.io directly, so the exact showcase list of hosts and the "last updated" date of the living spec are unconfirmed; the "26+" vs "~40" host counts come from secondary blogs (Jan-Jun 2026) and could not be reconciled.
- The date governance moved to AAIF is not established from a primary source.

## Key Question 3: Comparable "structured thinking toolkit" projects organized by category, and how they compare

### Takeaway
The closest comparables are skills-for-humanity itself (the upstream `human-avatar` repo: 34 domains, 200+ methods, `/s4h-` prefix, 231 stars), cc-thinking-skills (28 skills in 5 functional categories with a router skill and a partial eval audit), and claude-skills-mental-models (21 Munger-style models with disagreement analysis). skills-for-humanity is by far the broadest by category and method count; cc-thinking-skills is the only one with any published eval attempt; none has robust effectiveness evidence.

### Cited Findings
- `human-avatar/skills-for-humanity`: "Structured reasoning methodologies from history's most rigorous thinkers, packaged as Claude Code skills"; MIT; 231 stars, 24 forks, 39 commits; "5 clusters", "34 domains", "200+ methods" each prefixed `/s4h-` (e.g. `/s4h-decision-reversibility-analysis`); clusters: Think Sharper (logic, probability, decision, constraint, game theory, epistemology, investigation, economics, information, cognition), Think Differently (creativity, analogy, play, evolution, design), Think About People (communication, social, emotional, ethics, identity, narrative, psychology, mindset, writing, linguistics), Think in Time & Systems (systems, temporal, historical, resource, strategy, network, ecology), See More Clearly (aesthetic, sensory); cites de Bono, Meadows, Altshuller, Minto, Goldratt, Tetlock, Klein, Mill, Kant, Aristotle, Noddings, Rawls, Nash, Axelrod, Vickrey, Shapley, Ostrom, Shannon, Kahneman and others; install `npx @human-avatar/skills-for-humanity`; Claude Code via `.claude-plugin`; "No formal evals or effectiveness metrics provided" — [GitHub human-avatar/skills-for-humanity](https://github.com/human-avatar/skills-for-humanity)
- Design feature: "Each skill pauses before running to state what it's analyzing and ask how deep to go, and you can correct the framing at any point"; "Each domain routes to 4-20 individual methods" **[snippet]** — [README](https://github.com/human-avatar/skills-for-humanity/blob/main/README.md)
- The local working copy at `/home/user/skills-for-humanity` (remote `Matsuo-2017/skills-for-humanity`, MIT, copyright "2026 Finn Fitzsimons") contains 171 skill directories with category commands (`aesthetic`, `analogy`, `communication`, `constraint`, `creativity`, `decision`, `emotional`, `epistemology`, `ethics`, `game-theory`, `historical`, `identity`, `investigation`, `logic`, `mindset`, `narrative`, ...) and no `s4h-` prefix, i.e. it is a fork/variant that differs in naming and count from the upstream README — local filesystem observation (`ls skills | wc -l` = 171), not a web source
- It is listed in BehiSecc's awesome list as "Structured reasoning methodology skills for logic, decisions, creativity, ethics, writing, and strategy" — [BehiSecc/awesome-claude-skills](https://github.com/BehiSecc/awesome-claude-skills)
- cc-thinking-skills comparison points: 28 skills, functional (not disciplinary) categories, explicit `thinking-model-router` and `thinking-model-combination` meta-skills, multi-host (Claude Code, Copilot, Codex, Cursor), and an "eval-informed" audit that reports "28 active skills, all manual-only", "zero model calls and an unmeasured result", and one provisional +4.0pp finding for thinking-scientific-method that the authors say "is below the +5 point utility margin and has evidence gaps. Treat it as directional evidence, not an accuracy claim" — [GitHub tjboudreaux/cc-thinking-skills](https://github.com/tjboudreaux/cc-thinking-skills)
- claude-skills-mental-models comparison points: 21 models across 7 disciplines (thinking tools, systems, physical principles, evidence & statistics, economics, psychology, strategy); deliberately shrank from 98 to 21 for "quality/sourcing"; user-extensible via `.mental-models/`; multi-surface (skill, MCP, CLI, Python); no evals — [GitHub cyperx84/claude-skills-mental-models](https://github.com/cyperx84/claude-skills-mental-models)
- BMAD's 108-technique elicitation/brainstorming library (Six Thinking Hats, Delphi, Chain-of-Thought Scaffolding, Socratic pressure-testing, anti-consensus personas) is the largest single catalogue of named thinking techniques found, but it is packaged as workflow steps inside BMAD agents, not as standalone SKILL.md files per technique — [BMAD releases](https://github.com/bmad-code-org/BMAD-METHOD/releases)
- Anthropic's `discernment-nudge` occupies the epistemics niche officially, but is a single behavior (post-answer verification questions) rather than a toolkit — [discernment-nudge](https://github.com/anthropics/skills/blob/main/skills/discernment-nudge/SKILL.md)

### Inferences
- On breadth (34 domains / 200+ methods vs 28 vs 21) and on organizing principle (academic discipline with cluster routing vs functional stage vs Munger latticework), skills-for-humanity is the most encyclopedic project in this niche; cc-thinking-skills is more pragmatic (router + combination meta-skills, functional stages) and has the beginnings of an eval discipline; claude-skills-mental-models emphasizes cross-model disagreement and multi-surface delivery.
- All three share the same weakness: instructions-only markdown with no published evidence of reasoning uplift. Whichever project first ships a credible eval suite (see Q4 tooling) would differentiate itself.
- The proliferation of near-identical mental-model packs (98-model, 39-model, 28-model, 21-model variants, plus forks) suggests low switching cost and little consolidation; discoverability via awesome-lists is poor because none has a reasoning category.

### Gaps
- Star counts and commit activity for the reasoning packs come from single GitHub page reads; "maintenance status" beyond commit counts (e.g. last commit date, open issues) was not exposed by the fetched HTML.
- I did not find any academic or industry "prompt methodology library" (e.g. a curated CoT/ToT/self-consistency prompt pack) packaged in SKILL.md form; the thinking-tools that exist are mental-model libraries, not prompting-technique libraries.

## Key Question 4: How skills are evaluated, and evidence that skills improve reasoning quality

### Takeaway
By September 2026 there is a real evaluation toolchain (skill-creator evals since March 2026, `claude plugin eval` with six grader types and a no-plugin baseline since Claude Code v2.1.269 in September 2026, Superpowers' Quorum lab, plus community linters like skill-lint and skill-doctor) and a growing academic literature (SkillsBench, SkillJuror, SkillEval) showing curated *procedural* skills raise task pass rates by roughly +4 to +16 points on average, with wide domain variance. No study or repo isolates an uplift for general *reasoning* skills specifically, and the one reasoning-pack self-audit reports a sub-threshold +4pp with "evidence gaps".

### Cited Findings

**Official tooling**
- skill-creator announcement (2026-03-03): evals are "tests that check Claude does what you expect for a given prompt"; benchmark mode tracks "eval pass rate, elapsed time, and token usage"; "comparator agents" run blind A/B between two skill versions or skill vs baseline; description optimization across Anthropic's document skills "improved triggering on 5 out of 6 public skills" — [claude.com blog](https://claude.com/blog/improving-skill-creator-test-measure-and-refine-agent-skills)
- Claude Code docs on skill-creator: stores cases in `evals/evals.json`; spawns a subagent per case; writes `grading.json` and `benchmark.json` "for with-skill versus without-skill"; blind A/B version comparison; description tuning that "generates should-trigger and should-not-trigger prompts, measures the hit rate"; the recommended manual check is "a baseline comparison... with the skill available and again with it disabled"; the two eval formats (skill-creator vs plugin eval) "aren't interchangeable" — [Claude Code skills docs](https://code.claude.com/docs/en/skills)

- SkillsBench (arXiv 2602.12670, Feb 2026): "86 hand-built tasks across 11 professional domains"; "curated skills raise the average pass rate by 16%" with effects "ranging from +4.5 percentage points in software engineering to +51.9 percentage points in healthcare"; "self-generated skills offer no benefit, indicating that models struggle to create useful procedural knowledge despite benefiting from curated versions" **[unverified: arxiv/HF blocked; figures from search snippets]** — [arXiv 2602.12670](https://arxiv.org/abs/2602.12670); [skillsbench.ai PDF](https://www.skillsbench.ai/skillsbench.pdf)

### Inferences
- The evaluation paradigm that has won is *ablation*: same prompt with and without the skill, graded by regex/tool-use checks plus an LLM judge, repeated 3x. Both Anthropic tools and the academic benchmarks use it, which makes it the natural design for evaluating a reasoning toolkit.
- Existing evidence supports uplift for *procedural/domain* skills (checklists, file formats, APIs) where a grader can check a concrete artifact. Reasoning skills produce open-ended text, which the Claude Code docs themselves warn is where `llm` graders are least stable; that plausibly explains why no reasoning pack has published a credible delta.
- The SkillsBench result that self-generated skills add nothing, combined with SkillJuror's finding that organization/routing matters more than brevity, suggests that a categorized toolkit's router/dispatch layer (category commands, `thinking-model-router`) is the component most worth evaluating first.

### Gaps
